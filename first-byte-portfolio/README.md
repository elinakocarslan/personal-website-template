# First Byte Personal Portfolio

Welcome to your First Byte personal portfolio!

Today you will learn how to:

- Fork a repository
- Clone a repository
- Make changes locally
- Stage and commit changes
- Push changes to GitHub
- Submit a pull request

## Before You Begin

Make sure you have:

- GitHub account
- Git
- VS Code
- Node.js

## Step 1: Fork This Repository

Click the Fork button in the top-right corner.

## Step 2: Clone Your Fork

Click Code → HTTPS → Copy.

Then run:

git clone YOUR_REPOSITORY_URL

## Step 3: Open the Project

cd first-byte-portfolio

code .

## Step 4: Install Dependencies

npm install

## Step 5: Run the Website

npm run dev

Open the URL shown in your terminal.

## Step 6: Customize Your Portfolio

Change:

- Your name
- Bio
- Profile picture
- Skills
- Projects
- GitHub
- LinkedIn

## Step 7: Save Your Changes

git status

git add .

git commit -m "Customize my portfolio"

git push

Refresh your GitHub repository and find your changes!
